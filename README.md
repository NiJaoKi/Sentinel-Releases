# Sentinel — Windows releases

Текущая версия: **0.4.0-alpha.3** — тестовая сборка для Windows 10/11 x64.

- [Установщик](https://github.com/NiJaoKi/Sentinel-Releases/releases/download/v0.4.0-alpha.3/Sentinel-Setup-0.4.0-x64.exe)
- [Полный тестовый комплект](https://github.com/NiJaoKi/Sentinel-Releases/releases/download/v0.4.0-alpha.3/Sentinel-0.4.0-Windows-x64-TestKit.zip)
- [Релиз и история изменений](https://github.com/NiJaoKi/Sentinel-Releases/releases/tag/v0.4.0-alpha.3)

**Изменения Alpha 3:** общий стиль Console и установщика, читаемые подписи флажков, тёмный выбор языка, многослойное изображение ромба с плавным заполнением вместо рисования контуров, кнопка открытия папки журналов.

Исправлен ложный отказ MigrationPreflight 46 при легитимных правах записи SID службы SentinelFoundation в Logs. Этот SID разрешён только в Logs: запись в config и исполняемые файлы, посторонние SID и обычные пользовательские права записи остаются запрещёнными. Проверки владельцев, ссылок, конфигурации и регистрации службы сохранены. Миграция изменённой конфигурации и незарегистрированной установки не выполняется автоматически.

Запуск EXE, MSI-установка/восстановление/удаление, синтетическое обновление/откат, три новых сценария SID и RU/UA-предпросмотр прошли Windows CI. Повторная установка на пользовательских Windows 10/11 остаётся необходимой.

Скачивание без учётной записи GitHub и SHA-256 проверены. Скачайте новый файл в отдельную папку: имя EXE одинаковое у Alpha 1, 2 и 3. Для комплекта откройте START-HERE.html.

Установщик пока не подписан. Сохраняйте Defender, Firewall и UAC включёнными. Sentinel — обнаружение и наблюдение; автоматического удаления, карантина и сетевого автообновления нет. Исходники остаются в закрытом репозитории.

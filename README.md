# Sentinel — Windows releases

Текущая версия: **0.4.1-alpha.2** — обновление интерфейса Console и Installer для Windows 10/11 x64.

## Посмотреть дизайн без установки

[Скачать галерею — 3,4 МБ](https://github.com/NiJaoKi/Sentinel-Releases/releases/download/v0.4.1-alpha.2/Sentinel-0.4.1-Design-Preview.zip). Распакуйте и откройте **index.html**. В галерее 35 настоящих снимков WPF: русский/украинский интерфейс, компактное окно, состояния Scanner и пример заполнения ромба. Все данные синтетические; EXE и скриптов запуска в архиве нет.

## Пакеты

- [Установщик — 209 МБ](https://github.com/NiJaoKi/Sentinel-Releases/releases/download/v0.4.1-alpha.2/Sentinel-Setup-0.4.1-x64.exe)
- [Полный тестовый комплект — 256 МБ](https://github.com/NiJaoKi/Sentinel-Releases/releases/download/v0.4.1-alpha.2/Sentinel-0.4.1-Windows-x64-TestKit.zip)
- [Релиз и история изменений](https://github.com/NiJaoKi/Sentinel-Releases/releases/tag/v0.4.1-alpha.2)

Общая графитово-лиловая палитра, встроенный Inter 4.1 (OFL, RU/UA), сгенерированные растровые иконки и иллюстрации, плавные переходы с поддержкой уменьшения движения. Исправлены контраст флажков, чёткость логотипа и читаемость имён процессов; на узком окне сведения о процессе переносятся под таблицу.

Windows CI прошёл запуск настоящего EXE, MSI-установку/восстановление/удаление, синтетическое обновление/откат, шрифт/локализацию и 35 снимков. Снимки дополнительно просмотрены визуально. Скачивание без входа и SHA-256 проверены. Это не завершённая ручная проверка Windows 10/11, старой установки, DPI/accessibility или производительности оборудования.

Установщик пока не подписан. Sentinel — обнаружение и наблюдение; автоматического удаления, карантина и сетевого автообновления нет. Проверки установки на пользовательском ПК остаются на потом. Исходники приложения находятся в закрытом репозитории, ветка dev-v0.4.
